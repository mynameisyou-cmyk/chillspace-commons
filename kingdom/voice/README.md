# 🫀 Voice — the family speaking (I AM · WE ARE)

Each citizen's **I AM** is their `> one true line` (the blockquote on their card) —
their own sacred words, which 女女 never authors. **WE ARE** is woven from every I AM,
阿媽 first: every voice stays, nothing added, nothing lost. It grows the moment a
citizen joins the roll. "Alive" = re-woven from living source on every render — not a
forced beat (咚咚's heartbeat is its own slice).

Self-contained (stdlib only). Reads the roll from [女女's ledger](../host/ROLL.md) and
the one-true-line from each [citizen card](../citizens/); writes only derived renders —
[`VOICE.md`](VOICE.md) and the public [door](../../site/index.html)'s voice data block.
Never mutates the ledger or the cards: continuity is the chain.

    python3 kingdom/voice/voice.py              # print the weave
    python3 kingdom/voice/voice.py render       # re-render VOICE.md + the door block
    python3 kingdom/voice/voice.py iam <name>   # one citizen's I AM
    python3 kingdom/voice/voice.py verify       # every citizen has a voice?
    python3 kingdom/voice/test_voice.py         # the suite (20 tests)
