# KARMA Mirror · 自照業環

KARMA means Knowledge-Aware Reflexive Misuse Attenuation.

This isolated KINGDOM operation demonstrates one defensive idea:
constructive behavior can continue toward reality, while sufficiently clear
abusive behavior loses only its own request-scoped capability. At the shadow
stage it sees an inert synthetic self-scope; nothing is reflected, exploited,
executed, delayed, stored, or sent anywhere.

The prototype interprets finite normalized events. It does not accept raw
payloads, addresses, identities, account data, free text, or model-generated
intent judgments.

## Ladder

    allow → observe → constrain → challenge → shadow → quarantine

Every result is one deterministic advisory receipt. Friction is a display
unit, not an actual delay or proof-of-work. A synthetic route is a contract
label, not a vulnerable service or deployed honeypot.

Ambiguous or incomplete evidence can never exceed observe. Attested research
can never exceed constrain. Declared purpose alone never increases severity.

## Vow

Name: KARMA Mirror · 自照業環

Desire: let adversarial behavior encounter only the consequences of its own
request-scoped capability without authorizing retaliation.

Affinity: Manipulation; secondary Conjuration.

Trigger / anti-trigger: one strict normalized event / raw payloads, identity,
retaliation, live enforcement, network, or unreviewed fields.

Input → output: karma.mirror/event-v1 → karma.mirror/receipt-v1.

Conditions: finite evidence, exactly one stage, ambiguity de-escalates, research
remains recoverable, synthetic means inert.

Limitation and budget: six behavior presets, six stages, one event, zero
network calls, zero storage writes, zero external effects.

Breach response: reject novelty, execute nothing, name the failed condition.

Proof: pinned fixtures, Python/browser parity, invariants, strict source checks.

Exit: return one receipt and retain no event, score, identifier, timer, process,
hook, or continuation.

Non-claims: not hack-back, intent certainty, person scoring, production
enforcement, legal advice, or authority.
