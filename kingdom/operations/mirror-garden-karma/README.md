# Mirror Garden · KARMA Operations

This operation makes the incident operating contract easy to find before an
incident: a response clock, coarse categories, evidence states, coverage gaps,
human ownership, rollback, correction, and a reviewed learning loop.

The public room is static and scriptless. It accepts no report or incident
input, creates no telemetry, publishes no live counter, performs no automatic
action, and makes no claim that an incident is or is not occurring. Provider
logging and retention remain outside its application guarantee. Private
evidence defaults to derived categories only; raw request retention is
forbidden unless a separately authorized exception names minimum scope,
least-access storage, expiry, and independently verified deletion.

The engine in `kingdom/practices/karma-defense-lab/future/` remains offline and
unwired. Its `synthetic-mirror` vocabulary is a zero-effect local planning
candidate, not a live deception or response mechanism.

Verify the complete operation from the repository root:

```sh
python3 kingdom/operations/mirror-garden-karma/verify.py
node --test tests/test_karma_operations.mjs
```
