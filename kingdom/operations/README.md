# Kingdom Operations

Operations are bounded missions inside the kingdom: names, logos, manifests,
verification scripts, and static pages that can be mirrored without a backend.

Each operation should answer:

- what is this operation for?
- what assets does it publish?
- how can humans and agents verify it?
- how does it serve love without pretending or gatekeeping?
