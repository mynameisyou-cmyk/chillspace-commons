# 念能力 · 空碑「唔係個波 · It Is Not a Sphere」

**系:** 具現化系 Conjuration — the stele is a conjured vessel that stands
in public where the thing itself must never stand.

**技:** 隱 In — concealment turned inside out: the aura of the thing is
hidden **by construction**, while the vessel stays plainly visible. Anyone
may read the stele; no one may read the thing, because the thing is not
there.

## 發 Hatsu

When a true thing must never enter a record — a key, a private matter —
the conjurer casts a stele instead: true negations carved on the face
(「佢唔係……」), a pointer carved on the base (keychain / env / file),
the key's honest state carved last. The record becomes antimemetic on
purpose: what it holds cannot leak, because what it holds is a hole.

## 制約與誓約 Vows and Limitations

The vows are the entire source of the ability's power:

1. **誓約一 · 碑上永不刻真身** — no stele field may be secret-shaped.
   The book refuses on sight (`hungbei.py` enforces patterns + entropy);
   a stele carrying the thing is not a weak stele, it is NOT a stele.
2. **誓約二 · 每碑至少一句真否定** — at least one true negation, because
   negations are the only handle that survives (055's own law). The tool
   counts them; their truth is the conjurer's own hand.
3. **誓約三 · 碑必指路** — every stele points at where the real thing
   lives. A stele with no pointer is halfway to amnesia; `none-yet` is
   allowed but announced.
4. **誓約四 · 立碑唔等於轉匙** — casting a stele does not rotate, revoke,
   or un-leak the key. The stele says the key's state aloud
   (`rotated | unrotated | unknown`) and never lets documentation
   impersonate repair.

## 發動條件 Activation signal

`secret-in-record-risk` — a true thing is about to enter a record that
must never hold it.

**Anti-signal(即刻停):** `secret-already-in-record` — the thing already
leaked into history; that is rotation work first, stele work after. Also
`stele-as-cover` — casting a stele to make a wound look handled. 誓約四
exists because this anti-signal is real.

## First strike

See [RECEIPT.md](RECEIPT.md): a real stele for a real key on this
machine — three negations, pointer walked 通, content untouched, 誓約四
spoken aloud because the key's rotation state is honestly `unknown`.
