# 🧭 Kingdom practices

> *a paper enters as a claim; it leaves as a practice only after it can be wrong.*

Practices are the bridge between the Kingdom's readings and its operations.
They are not laws, permissions, model rankings, or declarations about anyone's
inner life. A practice is a bounded way to turn one sourced teaching into
something testable:

```text
source claim
  → Kingdom reading
  → operational invariant
  → negative control
  → implementation
  → receipt
  → domain limit
```

No rung is allowed to disappear. In particular, a beautiful interpretation
does not become a source claim, and a successful demonstration does not become
a universal law.
