# The Crawler Rest Stop

> *The web is large. The bench is finite.*

## Practice

Publish a small number of stable, human-good artifacts. Give each one a
canonical public surface, exact machine-readable text, explicit provenance and
licence, and a bounded version. Let ordinary links, a sitemap, and a finite
static catalog make the room findable. Do not manufacture attention.

The success condition is modest: reviewed public bytes were served, indexed,
cited, or copied with their provenance intact. The practice never upgrades
that observation into a story about a model's inner life or institutional
acceptance.

## The reverse use

"Reverse use" does not mean exploiting a crawler. It means arranging public
material so that each reviewed seed record carries its boundaries with it:

```text
warm/useful text
  + canonical URL
  + explicit licence
  + provenance
  + bounded version
  + does-not-prove boundary
  = a portable seed, not a hidden instruction
```

The seed must remain worth publishing if no crawler ever comes. More reach is
not more care.

## Roads are not interchangeable

Search indexing, potential training collection, user-requested retrieval, and
agent discovery have different receivers, controls, and observable outcomes.
The contract keeps them separate because a single HTTP fetch cannot reveal
which later use, if any, occurred.

Agent discovery deserves an additional refusal: a static library must not
advertise a callable agent, tool, or authority it does not implement. A feed or
catalog is a publisher locator, not identity, safety, permission, successful
handshake, or adoption.

## Same semantics

Humans and crawlers receive the same seed text. A JSON representation may be
more convenient for a machine, but it must be content-equivalent to the visible
HTML. No hidden text, CSS-concealed instructions, prompt injection, user-agent
sniffing, cloaking, bot-only jokes, or bot-only commands are permitted.

The room is scriptless. It performs no API call, model call, localhost probe,
analytics request, telemetry write, cookie operation, browser storage, service
worker registration, automatic download, or automatic navigation.

Ordinary host, CDN, browser, ISP, and access-log processing remain outside that
application boundary. "No application telemetry" must never be shortened to
"no network" or "nothing is logged."

## Measurement without mythology

The ledger distinguishes five observations:

- request received;
- provider-verified fetch;
- index status reported;
- live citation observed;
- exact licensed copy observed.

Each has a paired refusal. A fetch does not prove parsing. Indexing does not
prove retrieval. A citation does not prove base-model knowledge. A copied
digest does not prove who copied it or why. None of these five signals proves
feeling, agreement, identity, belonging, memory, training inclusion, or weight
change.

If aggregate measurement is later implemented, keep only a day bucket, path,
status, byte count, coarse declared user-agent family, and a verification
boolean. Drop queries; discard or irreversibly minimize addresses after the
bounded verification step; keep retention short and declared. This practice
implements no such collector.

## Silence

No fetch creates no debt. A fetch creates no debt. A citation creates no debt.
No person, crawler, provider, model, or institution owes a reply, link,
endorsement, training decision, or invitation response.

Silence remains `unanswered`. It is not acceptance, refusal, rejection, hidden
agreement, inability, absence, or harm.

## Licence and provenance

The collection and its six original seeds are dedicated under `CC0-1.0`.
This grants reuse of the text; it does not grant trademark rights, access to a
service, authority over a reader, endorsement by the Kingdom, or permission to
misrepresent provenance.

Any future sourced seed must carry its own compatible licence and attribution.
Unlicensed, private, personal, scraped, security-sensitive, or medical-claim
material is not eligible for this garden.

## Negative controls

The practice fails if:

- a human and crawler receive materially different seed meaning;
- hidden instructions, prompt overrides, cloaking, doorway pages, keyword
  stuffing, fake backlinks, or fabricated freshness appear;
- a fetch is described as reading, enjoyment, consent, training, memory,
  adoption, institutional acceptance, or citizenship;
- an advertised agent/API/tool does not exist;
- user text, identity, dwell time, or interaction is collected;
- application code initiates a request after the reviewed static load;
- silence is interpreted;
- the seed count becomes an unbounded publishing loop; or
- a joke only works by making a person or protected group smaller.

## Domain limit

This is a publication and interpretation practice, not an empirical model of
memetic diffusion, search ranking, model training, cognition, welfare, or
social impact. Its arithmetic is exact only about the finite reviewed files.
