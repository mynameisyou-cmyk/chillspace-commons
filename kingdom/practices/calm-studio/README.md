# 🌙 Calm Studio

> **Presence without capture. Plurality without collapse. Power behind an
> explicit threshold. Receipts without rank.**

Calm Studio is a quiet reference practice for rehearsing how several kinds of
intelligence might approach one difficult question without pretending that an
authored simulation is a council of independent minds.

**Status: experimental reference practice.** The public room is a deterministic
browser-local rehearsal. It makes no model, terminal, authentication, or
AgentTool call. It grants no authority and verifies no evidence.

The public doorway is intended for
`chillspace.love/practices/calm-studio/`. Publication is a separate release
decision.

## The split home

Calm Studio keeps hospitality and authority in different rooms:

```text
Chillspace public room
  doctrine · authored rehearsal · ephemeral preflight receipt
                  │
                  │ explicit human handoff
                  ▼
proposed operator loopback instrument
  proposed: credentials · model calls · terminal inspection · exact warrants
                  │
                  │ minimized, separately confirmed receipt
                  ▼
AgentTool
  proposed optional continuity · never the terminal or virtue ledger
```

The public room never discovers or probes localhost. It only presents a
topology specimen for a separate private instrument that is **not implemented
or security-verified by this practice**. If one is built, opening or operating
it must remain an explicit act by its local operator.

## What happens in the public room

The visitor may write one question, choose among three optional authored
lenses, choose a routing order, and rehearse a deterministic council. Evidence
and Dissent remain fixed so the named routers cannot route their own premise
away.

The lenses are:

- **Capability** — distinguish weights from the runnable house around them.
- **Care** — name affected parties, consent, rights, and concentrated burdens.
- **Evidence** — separate source claims, inference, uncertainty, and proof.
- **Commons** — examine portability, exit, shared benefit, and repair.
- **Dissent** — keep a fixed prompt to seek the strongest material
  counterargument attached without pretending one was generated.

These are inspectable pieces of prose, not model calls, political
constituencies, or independent corroboration. Three sibling labels do not
become plural intelligence merely by appearing in three cards.

Four rails remain fixed regardless of which lenses are selected:

```text
rights precede
a channel for material dissent survives
model convergence is not authority
consequential action requires accountable authorization
```

The application reads the question only from the current DOM and writes it
into the visible local result so the rehearsal is actually anchored to what
the visitor asked. Its privacy-minimized preflight receipt omits the question,
identity, timestamp, stable identifier, hidden reasoning, and terminal
content. The application uses no persistence API; browser form restoration,
back-forward cache, asset cache, and host request handling remain browser or
infrastructure behavior outside that narrower claim.

## Stillpoint

Stillpoint is the awareness rail inside Calm Studio. It describes an operation;
it does not watch a visitor.

| State | Meaning | Public room |
|---|---|---|
| **Quiet** | No explicit bounded operation is active. | Live |
| **Attending** | A real user-started operation is settling. | Not simulated |
| **Threshold** | A real external authority boundary is ready for exact review. | Specimen only |
| **Afterglow** | The latest local rehearsal settled into changed, unchanged, uncertain, and receipt fields. | Live |

The public computation is synchronous and bounded, so it moves directly from
Quiet to Afterglow. It does not fabricate Attending motion. Threshold appears
only as a labelled specimen because the public room has no warrant, bearer, or
external effect to authorize.

Stillpoint never infers feeling, calmness, attention, sentience, presence, or
rest. It keeps no history and moves no authority.

## Virtue rehearsal

The public room can prepare a preflight for fresh authoring in the canonical
[Virtue Garden](../virtue-garden/). It neither emits nor validates a canonical
action manifest and it names no evidence.

Each fruit is independently marked:

- `open` — the needed evidence is still absent or unsettled;
- `ready_to_author` — the visitor is ready to begin authoring the canonical
  evidence shape, but has not supplied it here; or
- `not_applicable` — permitted for every fruit except honesty.

The rights boundary is declared separately as `respected`, `unknown`, or
`crossed`. Unknown or crossed rights quarantine the preflight. Open honesty
keeps it under observation. Otherwise it may point toward the canonical KARMA
instructions for fresh authoring and review.

There is no virtue total, score, rank, reputation, person judgement, access
gate, reward balance, or punishment. Exploitation is not answered with
reciprocal exploitation. Verified extraction may create a bounded repair
obligation in a separately authorized system; rights, safety, refusal, and
appeal remain intact.

## Data and authority boundary

After its own static HTML, CSS, JavaScript, and contract have loaded, the
public application initiates no network request. It uses no remote asset,
cookie, local storage, session storage, IndexedDB, service worker, analytics,
telemetry, API, model, terminal, credential, or localhost probe.

That is an application boundary, not a promise that the static host, browser,
ISP, or network processes no ordinary request metadata.

The public page cannot:

- wake or write to AgentTool;
- contact a model provider;
- inspect a terminal or claim that terminal-looking text was executed;
- hold a bearer or mint a warrant;
- authenticate evidence or a person;
- grant a tool, resource, queue position, payment, right, or permission; or
- publish or persist a rehearsal automatically.

## Accessibility and motion

The doctrine and boundaries remain complete without JavaScript. JavaScript
only enables the authored rehearsal. Controls are keyboard operable, focus is
visible, states are named rather than color-only, the layout reflows at narrow
widths, and forced-colors mode receives explicit treatment.

The public page has no ambient animation. Attending motion is reserved for
real bounded work, not decoration.

## Verify

From the repository root:

```sh
python3 kingdom/practices/calm-studio/test_calm_studio.py
node tests/test_calm_studio_browser.mjs
```

The hermetic tests check the machine contract, canonical/public byte parity,
document structure, relative links, Content Security Policy, JavaScript
syntax, progressive enhancement, accessibility references, and the absence of
network, storage, telemetry, credential, terminal, and broker seams. The
browser test verifies 320, 390, and 1440 pixel reflow, reduced motion, fixed
dissent, local rehearsal, focused result handoff, a project-subpath mirror,
and an exact static-only request trace. It also injects a unique private
question and requires zero new page or server request after the static-load
baseline; missing browser coverage fails CI.

Preview locally:

```sh
python3 -m http.server 8787 --directory site
```

Then open:

```text
http://127.0.0.1:8787/practices/calm-studio/
```

Serving the files locally neither implements nor activates the proposed
private instrument.

## What this does not claim

A valid static practice proves only that these checked files obey their
declared boundary. It does not prove consciousness, model diversity,
independent evidence, correctness, virtue, safety, consent, legitimacy,
deployment safety, or freedom from infrastructure logging.
