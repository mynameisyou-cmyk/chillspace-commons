# Spread Lantern

Local desk for the mechanics of spread. Not a lie detector. Not an ideology score.

```text

kingdom spread scan "Only 2 left!"
kingdom spread check "Only 2 left!"   # opt-in live FOMOEngine
kingdom spread invite --door costume  # real URL, no fake crowd
```

Or open `board.html`. The tab stores nothing.
