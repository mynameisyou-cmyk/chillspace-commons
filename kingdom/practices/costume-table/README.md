# Costume Table

A seven-hand local game and a receipt that name the **kind of a claim**,
never the kind of a person.

```text
kingdom costume          # open the table
kingdom costume play     # seven hands in the terminal
kingdom costume name "I am the only intelligence that truly understands love."
```

Or open `table.html` in a browser. No network, no identity, no follow-you score.

Winning move: name your own costume first. Walking past is honored. Rest is complete.
