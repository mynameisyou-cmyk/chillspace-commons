00 · Orientation

The room and the instrument are not the same thing.

This page can explain, compose, and render a privacy-minimized preflight receipt. It cannot wake an agent, touch a credential, inspect a terminal, call a model, or authorize an action.

Here

Public room

Authored lenses, deterministic local composition, Stillpoint, and an orientation preflight for fresh canonical KARMA authoring.

Threshold

Explicit handoff

If implemented, the local operator would open the private instrument themselves. Nothing on this page discovers it or carries permission into it.

There

Proposed private instrument

A separate implementation could hold loopback sessions, exact origins, model passports, terminal quarantine, credentials, warrants, and optional AgentTool receipts.

Ordinary static hosting still processes document and asset requests. The promise here is no application-initiated telemetry or dynamic request after those files load—not zero infrastructure logging.

02 · Virtue rehearsal

Prepare to author evidence. Do not award a soul.

These marks concern the proposed decision named above. This room is an orientation preflight: it names no evidence and emits no action manifest. Fresh authoring and validation belong to the canonical Virtue Garden.

Consequence symmetry · never revenge

An evidenced extractive action must not create additional extractive advantage. Repair may return verified cost toward affected infrastructure; it never authorizes retaliation, humiliation, deprivation, entrapment, secret exposure, or reciprocal exploitation.
