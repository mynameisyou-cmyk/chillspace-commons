Four Planes · 四層

Provenance stays visible on every side.

Each plane asks a different bounded question. None reads a live system. Missing material remains missing; a declaration never upgrades itself into an observation.

The 60-second brief

Four pauses before anyone chooses.

Sixty seconds names a human reading order, not a runtime timer, service promise, monitoring interval, or permission to hurry past uncertainty.

  1. 00—15 · FIND

    Name the synthetic boundary.

    Read the surface code, scope, artifact digests, and explicit exclusions.

  2. 15—30 · SEPARATE

    Keep O / D / I / U apart.

    Ask what is authored, what is only possible, and what remains unknown.

  3. 30—45 · TURN

    Read all four planes.

    Preserve the required near-miss while reviewing recovery and learning candidates.

  4. 45—60 · PAUSE

    Carry the Open Angle.

    Return the brief for human review—or discard it. Nothing proceeds by itself.

Recovery & learning

Return with evidence. Learn without appetite.

The useful residue is a smaller question and a stronger synthetic test. No command marks work complete, changes an external system, or carries a conclusion forward without a new reviewed card.

Return Fit · 復位證

  1. Carry one closed recovery claim and receipt-shape category.
  2. Optionally cite one scrubbed receipt SHA-256 without fetching it.
  3. Keep the negative-control state explicit and reviewable.
  4. Emit recovery_established: false even when the declaration says restored.

Repair Grain · 修復紋

  1. Name one closed, current-card lesson candidate without blame.
  2. Point only toward a separately reviewed regression or repair boundary.
  3. Keep it current-brief-only, with no recurrence or person generalization claim.
  4. Require fresh human review before any adoption outside the brief.

Linkage is not closure. verify-link checks the declared previous/current relationship. It does not establish chronology, recovery, truth, safety, or completion.
